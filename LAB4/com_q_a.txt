# ชุดข้อมูลถาม-ตอบ: เกี่ยวกับคอมพิวเตอร์
# วัตถุประสงค์: ใช้เป็นฐานความรู้สำหรับระบบ RAG (Retrieval-Augmented Generation)
# ภาษา: ไทย | รูปแบบ: [หมวด] + Q: + A: แต่ละชุดคั่นด้วยบรรทัดว่าง
# ข้อจำกัด: เป็นข้อมูลเพื่อการศึกษา ไม่ใช่คำวินิจฉัยทางการแพทย์หรือคำปรึกษากฎหมายรายกรณี
# ================================================================
[หมวด: ฮาร์ดแวร์]
Q: CPU คืออะไร และทำหน้าที่อะไรในคอมพิวเตอร์
A: CPU (Central Processing Unit) คือหน่วยประมวลผลกลาง ทำหน้าที่ประมวลผลคำสั่งทั้งหมด ควบคุมการทำงานของอุปกรณ์ต่าง ๆ และคำนวณทางคณิตศาสตร์กับตรรกะ ถือเป็นสมองของคอมพิวเตอร์

[หมวด: ฮาร์ดแวร์]
Q: RAM กับ ROM ต่างกันอย่างไร
A: RAM เป็นหน่วยความจำชั่วคราวที่อ่านเขียนได้ ข้อมูลหายเมื่อปิดเครื่อง ส่วน ROM เป็นหน่วยความจำถาวรที่อ่านได้อย่างเดียว เก็บข้อมูลไว้แม้ไม่มีไฟเลี้ยง เช่น เฟิร์มแวร์ BIOS

[หมวด: ฮาร์ดแวร์]
Q: SSD ดีกว่า HDD อย่างไร
A: SSD ใช้หน่วยความจำแฟลชไม่มีชิ้นส่วนเคลื่อนไหว จึงอ่านเขียนเร็วกว่า HDD หลายเท่า ทนแรงกระแทกดีกว่า เสียงเงียบกว่า และกินไฟน้อยกว่า แต่ราคาต่อความจุสูงกว่า

[หมวด: ฮาร์ดแวร์]
Q: เมนบอร์ด (Mainboard) มีหน้าที่อะไร
A: เมนบอร์ดเป็นแผงวงจรหลักที่เชื่อมต่ออุปกรณ์ทุกชิ้นเข้าด้วยกัน ทั้ง CPU, RAM, การ์ดจอ และอุปกรณ์จัดเก็บข้อมูล พร้อมจ่ายไฟและส่งสัญญาณข้อมูลระหว่างกัน

[หมวด: ฮาร์ดแวร์]
Q: GPU คืออะไร และต่างจาก CPU อย่างไร
A: GPU คือหน่วยประมวลผลกราฟิก ออกแบบให้มีคอร์จำนวนมากสำหรับประมวลผลแบบขนาน เหมาะกับงานภาพและ AI ขณะที่ CPU มีคอร์น้อยกว่าแต่แต่ละคอร์ทรงพลัง เหมาะกับงานที่ทำตามลำดับ

[หมวด: ฮาร์ดแวร์]
Q: Power Supply Unit (PSU) สำคัญอย่างไร
A: PSU แปลงไฟฟ้ากระแสสลับจากปลั๊กเป็นไฟกระแสตรงที่อุปกรณ์ต้องการ หากกำลังไฟไม่พอหรือคุณภาพต่ำ เครื่องอาจดับเอง รีสตาร์ท หรือทำให้อุปกรณ์อื่นเสียหายได้

[หมวด: ฮาร์ดแวร์]
Q: Cache Memory คืออะไร
A: Cache คือหน่วยความจำความเร็วสูงขนาดเล็กที่อยู่ใกล้ CPU ใช้เก็บข้อมูลและคำสั่งที่ใช้บ่อย เพื่อลดเวลารอข้อมูลจาก RAM แบ่งเป็นระดับ L1, L2 และ L3

[หมวด: ฮาร์ดแวร์]
Q: อุปกรณ์อินพุตกับเอาต์พุตต่างกันอย่างไร
A: อุปกรณ์อินพุตใช้ป้อนข้อมูลเข้าเครื่อง เช่น คีย์บอร์ด เมาส์ สแกนเนอร์ ส่วนอุปกรณ์เอาต์พุตใช้แสดงผลลัพธ์ออกมา เช่น จอภาพ ลำโพง เครื่องพิมพ์

[หมวด: ฮาร์ดแวร์]
Q: Overclock คืออะไร มีความเสี่ยงอย่างไร
A: Overclock คือการเร่งความเร็วสัญญาณนาฬิกาของ CPU หรือ GPU ให้สูงกว่าค่ามาตรฐาน ช่วยเพิ่มประสิทธิภาพ แต่ทำให้ความร้อนและการใช้ไฟสูงขึ้น เสี่ยงต่อความไม่เสถียรและอายุการใช้งานที่สั้นลง

[หมวด: ฮาร์ดแวร์]
Q: BIOS และ UEFI คืออะไร
A: BIOS คือเฟิร์มแวร์ที่ทำงานตอนเปิดเครื่องเพื่อตรวจสอบฮาร์ดแวร์และบูตระบบปฏิบัติการ ส่วน UEFI เป็นรุ่นใหม่ที่บูตเร็วกว่า รองรับดิสก์ขนาดใหญ่เกิน 2TB และมีฟีเจอร์ความปลอดภัยอย่าง Secure Boot

[หมวด: ซอฟต์แวร์]
Q: ซอฟต์แวร์ระบบกับซอฟต์แวร์ประยุกต์ต่างกันอย่างไร
A: ซอฟต์แวร์ระบบควบคุมการทำงานพื้นฐานของเครื่อง เช่น ระบบปฏิบัติการและไดรเวอร์ ส่วนซอฟต์แวร์ประยุกต์คือโปรแกรมที่ผู้ใช้ใช้ทำงานเฉพาะด้าน เช่น Word, Excel, เบราว์เซอร์

[หมวด: ซอฟต์แวร์]
Q: Open Source Software คืออะไร
A: ซอฟต์แวร์โอเพนซอร์สคือซอฟต์แวร์ที่เปิดเผยซอร์สโค้ดให้ทุกคนดู แก้ไข และเผยแพร่ต่อได้ตามเงื่อนไขของสัญญาอนุญาต เช่น Linux, Firefox, VLC

[หมวด: ซอฟต์แวร์]
Q: Driver คืออะไร
A: ไดรเวอร์คือโปรแกรมที่ทำหน้าที่เป็นตัวกลางให้ระบบปฏิบัติการสื่อสารกับฮาร์ดแวร์ได้ถูกต้อง เช่น ไดรเวอร์การ์ดจอ ไดรเวอร์เครื่องพิมพ์

[หมวด: ซอฟต์แวร์]
Q: Firmware คืออะไร
A: เฟิร์มแวร์คือซอฟต์แวร์ที่ฝังอยู่ในชิปของอุปกรณ์ ทำหน้าที่ควบคุมการทำงานระดับล่างสุดของฮาร์ดแวร์ เช่น เฟิร์มแวร์ของเราเตอร์ SSD หรือกล้องดิจิทัล

[หมวด: ซอฟต์แวร์]
Q: Freeware, Shareware และ Trialware ต่างกันอย่างไร
A: Freeware ใช้ฟรีถาวรแต่ไม่เปิดซอร์สโค้ด Shareware ให้ทดลองใช้แล้วต้องจ่ายเพื่อปลดฟีเจอร์เต็ม ส่วน Trialware ใช้ฟรีในช่วงเวลาจำกัดก่อนต้องซื้อ

[หมวด: ซอฟต์แวร์]
Q: Virtual Machine คืออะไร
A: เครื่องเสมือนคือคอมพิวเตอร์จำลองที่รันอยู่บนเครื่องจริงผ่านซอฟต์แวร์ Hypervisor ทำให้ติดตั้งระบบปฏิบัติการหลายตัวบนเครื่องเดียวได้ เหมาะกับการทดสอบและแยกสภาพแวดล้อม

[หมวด: ซอฟต์แวร์]
Q: Compiler กับ Interpreter ต่างกันอย่างไร
A: Compiler แปลซอร์สโค้ดทั้งไฟล์เป็นภาษาเครื่องก่อนรัน ทำให้ทำงานเร็ว ส่วน Interpreter แปลและรันทีละบรรทัด ทำให้ดีบักง่ายแต่ช้ากว่า

[หมวด: ซอฟต์แวร์]
Q: Patch และ Update ต่างกันอย่างไร
A: Patch คือการแก้ไขเฉพาะจุด มักเป็นการอุดช่องโหว่หรือแก้บั๊กเร่งด่วน ส่วน Update เป็นการปรับปรุงที่ครอบคลุมกว่า อาจรวมฟีเจอร์ใหม่และการปรับปรุงประสิทธิภาพ

[หมวด: ซอฟต์แวร์]
Q: API คืออะไร
A: API (Application Programming Interface) คือชุดข้อกำหนดที่ให้โปรแกรมหนึ่งเรียกใช้ฟังก์ชันหรือข้อมูลของอีกโปรแกรมได้ โดยไม่ต้องรู้รายละเอียดภายใน เช่น API แผนที่ API ชำระเงิน

[หมวด: ซอฟต์แวร์]
Q: Middleware คืออะไร
A: Middleware คือซอฟต์แวร์ตัวกลางที่เชื่อมระบบหรือแอปพลิเคชันต่าง ๆ ให้สื่อสารกันได้ เช่น Message Broker, Application Server หรือระบบจัดการธุรกรรม

[หมวด: ระบบปฏิบัติการ]
Q: ระบบปฏิบัติการ (OS) ทำหน้าที่อะไร
A: OS ทำหน้าที่จัดการทรัพยากรของเครื่อง ทั้งหน่วยประมวลผล หน่วยความจำ อุปกรณ์จัดเก็บข้อมูล และไฟล์ พร้อมเป็นตัวกลางระหว่างผู้ใช้ ซอฟต์แวร์ และฮาร์ดแวร์

[หมวด: ระบบปฏิบัติการ]
Q: Process กับ Thread ต่างกันอย่างไร
A: Process คือโปรแกรมที่กำลังทำงานและมีพื้นที่หน่วยความจำของตัวเอง ส่วน Thread คือหน่วยย่อยของการทำงานภายใน Process ที่แชร์หน่วยความจำร่วมกัน จึงสลับสับเปลี่ยนได้เร็วกว่า

[หมวด: ระบบปฏิบัติการ]
Q: Virtual Memory คืออะไร
A: หน่วยความจำเสมือนคือเทคนิคที่ OS ใช้พื้นที่บนดิสก์เสมือนเป็น RAM เพิ่มเติม ทำให้รันโปรแกรมที่ต้องการหน่วยความจำมากกว่า RAM จริงได้ แต่จะช้ากว่าการใช้ RAM โดยตรง

[หมวด: ระบบปฏิบัติการ]
Q: Deadlock คืออะไร
A: Deadlock คือสภาวะที่หลายกระบวนการต่างรอทรัพยากรที่อีกฝ่ายถือครองอยู่ ทำให้ไม่มีใครทำงานต่อได้ เกิดขึ้นเมื่อครบเงื่อนไข 4 ข้อ ได้แก่ mutual exclusion, hold and wait, no preemption และ circular wait

[หมวด: ระบบปฏิบัติการ]
Q: Kernel คืออะไร
A: เคอร์เนลคือแกนกลางของระบบปฏิบัติการ ทำหน้าที่จัดการหน่วยความจำ จัดคิวการทำงานของ CPU ควบคุมอุปกรณ์ และให้บริการ System Call แก่โปรแกรมต่าง ๆ

[หมวด: ระบบปฏิบัติการ]
Q: File System คืออะไร มีแบบใดบ้าง
A: ระบบไฟล์คือวิธีจัดระเบียบและจัดเก็บข้อมูลบนสื่อบันทึก ตัวอย่างที่พบบ่อยคือ NTFS และ FAT32 บน Windows, APFS บน macOS, ext4 และ XFS บน Linux

[หมวด: ระบบปฏิบัติการ]
Q: Linux คืออะไร และมี Distribution ใดบ้าง
A: Linux คือเคอร์เนลโอเพนซอร์สที่ถูกนำมาประกอบเป็นระบบปฏิบัติการหลายรูปแบบ เรียกว่า Distribution เช่น Ubuntu, Debian, Fedora, Arch Linux และ Red Hat Enterprise Linux

[หมวด: ระบบปฏิบัติการ]
Q: Multitasking คืออะไร
A: Multitasking คือความสามารถของ OS ในการรันหลายงานพร้อมกัน โดยสลับการใช้ CPU อย่างรวดเร็วจนผู้ใช้รู้สึกว่าทุกงานทำงานไปพร้อมกัน

[หมวด: ระบบปฏิบัติการ]
Q: Booting คืออะไร
A: การบูตคือกระบวนการเริ่มต้นระบบตั้งแต่เปิดเครื่อง โดยเฟิร์มแวร์จะตรวจสอบฮาร์ดแวร์ (POST) แล้วโหลด Bootloader เพื่อนำเคอร์เนลของระบบปฏิบัติการเข้าสู่หน่วยความจำ

[หมวด: ระบบปฏิบัติการ]
Q: Swap Space คืออะไร
A: Swap คือพื้นที่บนดิสก์ที่ OS ใช้ย้ายข้อมูลบางส่วนออกจาก RAM เมื่อหน่วยความจำเต็ม ช่วยให้ระบบทำงานต่อได้ แต่หากใช้มากเกินไปจะทำให้เครื่องช้าลงชัดเจน

[หมวด: เครือข่าย]
Q: LAN, MAN และ WAN ต่างกันอย่างไร
A: LAN คือเครือข่ายขนาดเล็กในพื้นที่จำกัด เช่น ในอาคาร MAN ครอบคลุมระดับเมือง ส่วน WAN ครอบคลุมพื้นที่กว้างระดับประเทศหรือทั่วโลก เช่น อินเทอร์เน็ต

[หมวด: เครือข่าย]
Q: IP Address คืออะไร
A: IP Address คือหมายเลขประจำตัวของอุปกรณ์บนเครือข่าย ใช้ระบุต้นทางและปลายทางของข้อมูล ปัจจุบันมีทั้ง IPv4 ขนาด 32 บิต และ IPv6 ขนาด 128 บิต

[หมวด: เครือข่าย]
Q: TCP กับ UDP ต่างกันอย่างไร
A: TCP เป็นโพรโทคอลที่สร้างการเชื่อมต่อและรับประกันว่าข้อมูลถึงครบถ้วนตามลำดับ ส่วน UDP ส่งข้อมูลโดยไม่ยืนยันผล ทำให้เร็วกว่าแต่มีโอกาสสูญหาย เหมาะกับสตรีมมิงและเกม

[หมวด: เครือข่าย]
Q: DNS ทำงานอย่างไร
A: DNS ทำหน้าที่แปลงชื่อโดเมนที่คนอ่านเข้าใจ เช่น example.com ให้เป็น IP Address ที่เครื่องใช้ติดต่อกัน โดยสอบถามผ่านลำดับชั้นของเซิร์ฟเวอร์ตั้งแต่ Root ไปจนถึง Authoritative Server

[หมวด: เครือข่าย]
Q: Router กับ Switch ต่างกันอย่างไร
A: Switch ทำงานในเครือข่ายเดียวกันโดยส่งข้อมูลตาม MAC Address ส่วน Router เชื่อมต่อระหว่างเครือข่ายต่างวงและเลือกเส้นทางส่งข้อมูลตาม IP Address

[หมวด: เครือข่าย]
Q: OSI Model มีกี่ชั้น อะไรบ้าง
A: มี 7 ชั้น ได้แก่ Physical, Data Link, Network, Transport, Session, Presentation และ Application ใช้เป็นแบบจำลองอ้างอิงในการอธิบายการสื่อสารบนเครือข่าย

[หมวด: เครือข่าย]
Q: DHCP คืออะไร
A: DHCP คือโพรโทคอลที่แจกจ่าย IP Address และค่าคอนฟิกเครือข่ายอื่น ๆ เช่น Gateway และ DNS ให้อุปกรณ์โดยอัตโนมัติ ช่วยลดภาระการตั้งค่าด้วยมือ

[หมวด: เครือข่าย]
Q: NAT คืออะไร
A: NAT คือการแปลง IP Address ภายในเครือข่ายส่วนตัวให้เป็น IP สาธารณะเมื่อออกอินเทอร์เน็ต ช่วยประหยัด IPv4 และซ่อนโครงสร้างเครือข่ายภายในไว้

[หมวด: เครือข่าย]
Q: Bandwidth กับ Latency ต่างกันอย่างไร

Q: Binary Search ทำงานอย่างไร
A: การค้นหาแบบทวิภาคใช้กับข้อมูลที่เรียงลำดับแล้ว โดยเปรียบเทียบกับค่ากลางแล้วตัดครึ่งข้อมูลที่ไม่ต้องค้นหาออกทุกรอบ ทำให้มีความซับซ้อนเพียง O(log n)

Q: อัลกอริทึมการเรียงลำดับที่นิยมมีอะไรบ้าง
A: ที่พบบ่อยคือ Bubble Sort และ Insertion Sort ที่เข้าใจง่ายแต่ช้าที่ O(n^2) ส่วน Merge Sort และ Quick Sort เร็วกว่าที่ระดับ O(n log n) โดยเฉลี่ย

Q: Exception Handling คืออะไร
A: คือกลไกดักจับและจัดการข้อผิดพลาดขณะโปรแกรมทำงาน โดยใช้โครงสร้างอย่าง try-catch-finally ทำให้โปรแกรมไม่หยุดทำงานกะทันหันและแสดงข้อความที่เหมาะสมแก่ผู้ใช้

Q: Unit Testing คืออะไร
A: Unit Testing คือการทดสอบหน่วยย่อยที่สุดของโค้ด เช่น ฟังก์ชันหรือเมธอด แยกจากส่วนอื่น เพื่อยืนยันว่าทำงานถูกต้องตามที่คาดหวัง และช่วยจับบั๊กตั้งแต่ระยะเริ่มต้น

Q: Refactoring คืออะไร
A: Refactoring คือการปรับปรุงโครงสร้างภายในของโค้ดให้อ่านง่ายและดูแลง่การเชื่อมต่อกับโมเดลขัดข้อง กรุณาลองใหม่อีกครั้ง
